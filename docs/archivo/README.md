# `docs/archivo/` — documentos cerrados

Aquí viven los cuestionarios y tests cuyo contenido **ya está absorbido en
`biblia-del-juego.md` y codeado**. No son borradores ni notas sueltas: son las
sesiones de las que salieron las decisiones numeradas de §5.

**Por qué se archivan y no se borran.** Cada decisión de la biblia dice *qué* se
decidió. Estos archivos dicen *qué se preguntó y qué respondió Bazalo*, que es la
única forma de reconstruir el porqué cuando dentro de un año alguien quiera
reabrir algo. Borrarlos ahorraría ocho archivos y costaría la trazabilidad
entera.

**Qué NO hay que hacer con ellos.** No se responden, no se actualizan y no se
citan como fuente viva. Si uno contradice a la biblia, **manda la biblia**: estos
documentos están congelados en la fecha en que se cerraron.
